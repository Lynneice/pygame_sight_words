🎮 GAME MECHANICS

  SPEED SYSTEM:
    Base Speed:    3.0
    Max Speed:     10.0
    Correct word:  +0.2 speed
    Wrong word:    -0.5 speed

  RING SYSTEM:
    Correct read:  +1 ring
    Wrong read:    -1 ring
    Minimum:       0 rings

  CONTROLS:
    SPACE    - Jump
    R        - Speak word
    P        - Pause
    ESC      - Quit
